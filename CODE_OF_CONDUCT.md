# Тәртип кодексы / Code of Conduct

*Татарча беренче, аннары инглизчә.*

## Татарча

Tatar-Native Computing Foundation җәмгыяте — кунакчыл өстәл кебек: монда һәркемгә
урын бар. Без татар мәдәниятен хөрмәт итеп, аны яратып эшлибез.

### Безнең кыйммәтләр

- **Хөрмәт.** Катнашучыларга — милләтенә, теленә, тәҗрибәсенә карамастан — хөрмәт.
- **Кунакчыллык.** Яңа кешене чәй белән каршы алабыз, ярдәм итәбез, көлдермибез.
- **Төгәллек.** Тел һәм мәдәният мәсьәләләрендә — чыганакка таян, бәхәсне
  хөрмәт белән алып бар.
- **Мәдәни ихтирам.** Бу проект татар мәдәниятен **данлый**, көлке объектына
  әйләндерми. Стереотипларны мыскыл итү — кабул ителми.

### Кабул ителми

Кимсетү, эзәрлекләү, дошманлык, милли/дини мыскыл итү, троллинг, шәхси
һөҗүмнәр — тыела.

### Хәбәр итү

Проблема булса — оешма мәйнтейнерларына языгыз (GitHub Issues яки оешма
контактлары аша). Һәр хәбәр карала.

## English

The Tatar-Native Computing Foundation community is like a hospitable table:
there's room for everyone. We work with respect and love for Tatar culture.

**Our values:** respect for all participants regardless of nationality, language,
or experience; hospitality toward newcomers; accuracy in matters of language and
culture (cite sources, argue respectfully); and **cultural reverence** — this
project *celebrates* Tatar culture, it does not make it the butt of a joke;
mocking stereotypes is not acceptable.

**Not tolerated:** discrimination, harassment, hostility, ethnic/religious insult,
trolling, personal attacks.

**Reporting:** contact the organization maintainers via GitHub Issues or the
organization's contacts. Every report is reviewed.
